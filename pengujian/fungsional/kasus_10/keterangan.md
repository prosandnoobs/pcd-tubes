# Kasus 10: Susun Manual, memulai permainan M=3

**Langkah:** Mengunggah ZIP puzzle 3 x 3 dengan rotasi ke Susun Manual.

**Hasil yang diharapkan:** Grid 3 x 3 kosong dan 9 potongan berada di tray.

**Berkas masukan:** folder `input/`, bisa diunggah langsung ke aplikasi. Folder `output/` (jika ada) berisi ZIP yang dihasilkan Generator.
